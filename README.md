## 👨‍💻 Sobre mí

Soy **Ingeniero en Sistemas Computacionales, con Maestría en TIC y orgullosamente docente universitario**. Disfruto enseñar programación desde sus fundamentos y convertir problemas cotidianos en soluciones tecnológicas comprensibles, prácticas y útiles.

Mi trabajo combina la **formación de estudiantes**, el **desarrollo de aplicaciones** y la **experimentación con electrónica e Internet de las Cosas (IoT)**. Me interesa especialmente crear proyectos que conecten el software con el mundo físico.

- 🎓 **Docencia:** programación, algoritmos, herramientas digitales y formación tecnológica.
- 🐍 **Programación:** Python, PHP, JavaScript y desarrollo web.
- 🔌 **Hardware e IoT:** ESP32, ESP8266, Arduino, sensores y comunicación Bluetooth/BLE.
- 🗄️ **Datos y plataformas:** MySQL, Moodle y herramientas para proyectos académicos.
- 🧪 **Prototipado:** soluciones educativas y dispositivos tecnológicos aplicados.

## 🚀 Proyectos destacados

### 🐍 [Fundamentos de Programación](https://github.com/danielmaupome/FundamentosProgramacion)

Repositorio de apoyo para la asignatura **Fundamentos de Programación (AED-1285)** del Tecnológico Nacional de México. Incluye ejercicios de Python para acompañar el aprendizaje de algoritmos, estructuras de control y resolución de problemas.

### 🧦 SensiaSox · Tecnología wearable

Proyecto de prototipado orientado al **monitoreo de presión ejercida por calcetines**, mediante sensores, microcontroladores y comunicación con una aplicación móvil. Explora cómo la electrónica y el software pueden contribuir al desarrollo de tecnologías de apoyo para la salud.

> Proyecto en desarrollo. No se presenta como dispositivo médico validado.
